# 审美校准案例

把本文件用作方法边界与反馈依据，不作成稿素材库。以下为既有共创规范的摘要，整理日期为2026-11-14；来源为现有技能及《01_项目指令_可直接粘贴(1).md》。未保存原稿的条目不构造前后对照，不把方法认可等同于某篇稿件定稿。

## 01｜用细节证明母题

- 来源状态：已保存的长期创作规范；原稿未保留。
- 问题：沿着相识、恋爱、求婚依次复述，容易成为流水账。
- 方法：先确定一句话关系立意，选1–3处真实细节证明，再由细节解释关系，最后升华。
- 边界：开场只用一个主技巧、抓1–2个核心点；不为完成结构捏造第三处细节。

## 02｜听得懂，同时有余味

- 来源状态：已保存的“过白／过绕／不深刻”反馈处理规范；原稿未保留。
- 方法：从可感知的生活入口进入，在人物的选择、变化与相处方式里增加理解；让结尾给开头带来新含义。
- 边界：不以生僻意象充当深度，不把“通俗”理解成直接说教，不默认所有文案都需要外部典故。

## 03｜适中的篇幅

- 来源状态：已保存的“太长／太短”反馈处理规范；原稿未保留。
- 方法：长稿先删同义升华与无关材料；短稿补真实细节及其意义。保留入口、证据、转折和落点的完整性。
- 边界：根据本场节奏和用户意见决定长度，不设所有开场通用的硬字数；朗读时长只给有依据的估算。

## 04｜合伙人到余地

- 来源状态：现有风格资料中已保存的方法案例；未在本文件保存完整定稿。
- 素材条件：真实工作与共同事业为两人关系提供支撑。
- 方法：从共同处理工作与生活的关系，递进到亲密关系中给予彼此的空间。
- 边界：只迁移“熟悉词语切入 → 关系理解递进”的方法；新案缺少证据时不用这个母题，也不声称知道未取得的具体相处细节。

## 05｜相识多年不等于相爱多年

- 来源状态：项目指令中有明确事实边界；人物已匿名化。
- 素材条件：高中同桌，相识约14年，中间偶尔联系和打游戏，真正相爱约一年多。
- 方法：如使用“念念不忘、回响”方向，只表达这段缘分在当下获得回应的意义，避免断言始终暗恋或等待。
- 边界：不得写成14年恋爱、14年守候或从未间断的感情；这是事实校核案例，不是下一场的默认主题。

## 06｜旁白等待动作

- 来源状态：已保存的动态送戒与现场执行规范。
- 素材条件：蝴蝶等动态道具把婚戒送到新人手中，运动时间未确认。
- 方法：按启动、运动中、确认落稳后三段安排短句和留白，到位后才引导交换。
- 边界：不预设固定飞行秒数；不在道具仍运动时宣布已经落在掌心。轻松、少煽情等本场偏好不升格成通用风格禁令。
