# 风格与技法

## 三种风格
- 王洋：温柔见证、自然口语、内心细节与轻哲理。从日常事实总结关系，让情绪逐渐沉淀；不要让新人沦为观点的例证。
- 入境：新人一句话、真实物件、音乐、现场设计或字词 → 解读立意 → 事实佐证 → 递进回收 → 内容化互动。文艺入口必须有依据，最终落回两个人。
- 山竹：干净、清新、带笑意的生活洞察，用平常话带出更深一层，不宏大、不雕琢过度。

尊重本场指定风格；可融合，但不无故改换主题。

## 主技巧选择
- 回环：开头的问题、词语或画面在结尾获得新的理解。
- 角色视角：从真实关系中的另一角度观察；保持见证视角，不制造第一人称独白。
- 地理标记：有意义的校园、城市、家门前；避免旅游导览。
- 时空影像：真实照片或影像是时间证据；不把“影像”强加到所有婚礼。
- 词语重释：从熟悉词语打开关系理解，不玩脱离故事的字谜。
- 象征意象：雏菊、月亮、河流、卡农等仅在确有关联时使用。
- 生活现场：雨、草坪、天台、空间动线可自然引入，不能预设尚未确认的天气。

## 旧案迁移边界
- “合伙人→余地”：可学从共同事业走向相处空间的递进，不自动用于下一对新人。
- “影像→被记录的幸福”：须有本场真实影像或阶段性记忆支持。
- “念念不忘→回响”：可表达多年后相遇的意义，不能由相识多年推断多年暗恋。

以上是方法案例，不是通用台词或待套模板；本技能依据已保存的共创规范整理，未内置完整《入境》手册。
