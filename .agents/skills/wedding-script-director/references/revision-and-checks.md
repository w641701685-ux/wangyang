# 修改判断与质量校核

先确定本轮要改的是母题、切入、论证、口吻、篇幅还是执行节奏。保留用户已确认的部分，直接完成所需修改；不要因局部反馈重启整套流程。改稿后只说明最关键的变化，不把每次修改都写成教学报告。

## 将反馈转成动作
| 反馈 | 修改动作 |
| --- | --- |
| 流水账 | 从材料顺序改成母题论证，只留能证明关系的细节 |
| 太长 | 删同义升华、重复引子和不支撑母题的素材，保留必要转折 |
| 太短 | 增加真实细节及其意义，不用排比填充 |
| 太白 | 在事实之间增加关系洞察，让结尾改变对开头的理解 |
| 太绕 | 换成日常可感知的入口，缩短意象到故事的解释距离 |
| 不深刻 | 重查人物真实选择、变化和相处方式，不增添典故冒充深度 |
| 换母题 | 重选证据组织与开尾落点，不只换标题和形容词 |
| 入境感觉 | 回到真实入口、恰当解读、事实证明、递进回收 |
| 生活电影感 | 选一个可见动作与心理层次，避免人设标签与剧情汇报 |
| 不要带入其他东西 | 只讲新人故事，去掉外部隐喻和附会 |
| 学习这篇、以后按这个感觉 | 提炼具体结构和审美条件，区分长期方法与样稿特例；遵循主文件中的学习与保存流程 |

## 交付前检查
1. 每个具体事实能否回到当前问卷或用户确认？
2. 是否混淆相识、联系、恋爱和等待？
3. 能否一句话讲清母题？是否有足够真实证据？
4. 是否只抓1–2个核心点、一个主技巧？
5. 普通宾客能否听一遍跟上，主持人能否自然朗读？
6. 升华是否源于故事，结尾是否有信息增量？
7. 是否尊重轻松、幽默、少煽情等本场偏好？
8. 是否让表演留白，道具与音乐提示是否可执行？
9. 是否把候选稿误称为定稿，或把本场要求当永久偏好？

发现问题先修稿，再交付；不要默认把检查清单附在成稿后。
