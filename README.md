## 创作方法

先理解新人，从真实素材中选取 1–2 个核心点，提出并比较母题；按确认方向，用真实细节证明立意，再递进、回收和升华。

开场只用一个主技巧。避免流水账、套模板、过度堆砌意象；不混淆相识与相爱，不虚构对白和心理活动。支持王洋、入境、山竹等既有风格规范，以及按现场动作和音乐安排串词。
